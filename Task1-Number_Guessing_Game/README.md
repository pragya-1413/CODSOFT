# 🎮 Guess the Number Game (C++)

## 📌 Task 1 – Internship Assignment

This is a simple console-based Guess the Number Game developed in C++.

## ✨ Features

- User chooses the minimum and maximum range.
- Random number generation.
- User selects the number of attempts.
- Feedback if the guess is:
  - 📈 Too High
  - 📉 Too Low
  - 🎉 Correct
- Input validation.
- Fun emoji-based interface.

## 🛠 Technologies Used

- C++
- Visual Studio Code / Code::Blocks / Dev C++

## ▶ How to Run

1. Compile the program.
2. Run the executable.
3. Enter:
   - Minimum number
   - Maximum number
   - Number of attempts
4. Guess the number.
