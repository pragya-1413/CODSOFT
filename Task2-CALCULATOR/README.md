# 🧮 Simple Calculator (C++)

## 📌 Task 2 – Internship Assignment

This project is a simple console-based Calculator developed in C++ as part of my internship assignment.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User-friendly menu
- Handles invalid operator selection
- Clean console interface

## 🛠 Technologies Used

- C++
- Object-Oriented Programming Basics
- Visual Studio Code / Cursor / Code::Blocks

## ▶ How to Run

1. Compile the program.
2. Run the executable.
3. Enter two numbers.
4. Choose an operation:
   - +
   - -
   - *
   - /
5. View the result.

## 📷 Sample Output

```
===== SIMPLE CALCULATOR =====

Enter first number: 25
Enter second number: 5

Choose an operation:
+
-
*
/

Enter operator: *

Result = 125
```
