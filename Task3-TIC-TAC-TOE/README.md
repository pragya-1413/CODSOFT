# ❌⭕ Tic-Tac-Toe Game (C++)

## 📌 Task 3 – Internship Assignment

This project is a simple console-based **Tic-Tac-Toe Game** developed in **C++** as part of my internship assignment.

## 🎮 About the Project

Tic-Tac-Toe is a two-player game where Player **X** and Player **O** take turns marking spaces on a **3×3 grid**. The first player to place three of their marks in a row, column, or diagonal wins the game. If all spaces are filled and no player wins, the game ends in a draw.

## ✨ Features

- 🎲 Two-player mode
- ❌ Player X and ⭕ Player O alternate turns
- 📋 Numbered board (1–9)
- ✅ Detects winner
- 🤝 Detects draw
- 🚫 Prevents overwriting occupied positions
- 💻 Simple console interface
- 📚 Beginner-friendly code

## 🛠 Technologies Used

- C++
- Console Application
- Visual Studio Code / Cursor / Code::Blocks

## ▶ How to Run

1. Clone or download this repository.
2. Open `TicTacToe.cpp` in your C++ IDE or editor.
3. Compile the program.
4. Run the executable.
5. Follow the on-screen instructions to play.

## 🎯 Game Rules

- Player **X** starts first.
- Enter a number between **1 and 9** to place your mark.
- The number corresponds to the board position.
- The first player to make **3 marks in a row, column, or diagonal** wins.
- If all positions are filled without a winner, the game ends in a draw.
